# UT 시나리오: 근거를 확인하고 병합하기

1. 워크스페이스 진입 시 Jordan의 개발 요청 D-7 알림을 확인한다.
2. 디자인 비교에서 작성자 이름 없이 시안 A/B/C/D를 살펴보고 원하는 부분을 조합한다.
3. 병합 요청을 눌러 조합을 충돌 리스트에 등록한다.
4. 상태가 맨 앞에 있는 리스트에서 검토할 항목을 열고 현재 구현과 디자인 기준을 확인한다.
5. History에서 변경 이유, 이전 버전과 검토 기록을 확인하여 어떤 내용을 유지할지 판단한다.
6. Overview로 돌아와 비교 카드 안의 ‘현재 구현으로 합치기’ 또는 ‘디자인 기준으로 합치기’를 누른다. 조합 시안은 디자인 비교에서 선택한 결과를 검토한다.
7. 검토를 요청한다. 필요한 경우 검토자별 또는 전체 리마인드를 보낸다.
8. 다른 검토자는 4초 후부터 2초 간격으로 자동 승인한다. 참가자 본인의 승인은 직접 진행한다. 작성자는 승인 대상에서 제외된다.
9. 필수 승인과 검사를 완료한 뒤 병합한다.

관찰 항목: 상태·위험도 구분, History 근거 탐색, 카드 선택 발견, 선택 결과 이해, 검토 요청과 최종 병합의 구분.

자동 승인은 UT 데모 동작이다. 승인 요청 후 내용이 바뀌면 예정된 승인은 취소된다. 새 검토 요청이나 리마인드로 다시 시작한다. 화면만 닫아도 워크스페이스 내 요청은 계속 진행되며, 새로고침 후에는 저장된 요청 시간이 지난 다른 검토자의 응답을 반영한다.
